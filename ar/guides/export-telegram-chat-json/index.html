كيفية تصدير محادثة تيليجرام بصيغة JSON

لإنشاء ملخص لمحادثاتك تحتاج إلى ملف واحد: result.json تصدّره من تطبيق Telegram Desktop. تطبيقات الهاتف لا تستطيع تصدير المحادثات، لذا تحتاج تطبيق الحاسوب (Windows أو macOS أو Linux). تستغرق العملية دقيقتين تقريباً.

تصدير بياناتك

  1. افتح Telegram Desktop واذهب إلى Settings ← Advanced ← Export Telegram data (الإعدادات ← متقدم ← تصدير بيانات تيليجرام).
  2. اختر ما تريد تضمينه. يكفي للملخص المحادثات الشخصية (والمجموعات التي تريدها). ألغِ تحديد الصور والفيديوهات والرسائل الصوتية والملصقات والملفات، فيبقى التصدير صغيراً وسريعاً.
  3. اجعل الصيغة Machine-readable JSON. تصدير HTML لن يعمل.
  4. يمكنك تحديد فترة زمنية، مثل هذه السنة فقط.
  5. اضغط Export وانتظر. قد يطلب منك تيليجرام تأكيد الطلب من جهاز آخر مسجّل الدخول.
  6. افتح مجلد التصدير وستجد الملف result.json.

تصدير محادثة واحدة فقط

افتح المحادثة، واضغط على قائمة (⋮) في أعلى المحادثة، ثم اختر Export chat history (تصدير سجل المحادثة). استخدم الخيارات نفسها: بلا وسائط، وصيغة Machine-readable JSON. قد تختلف أسماء القوائم قليلاً بين إصدارات Telegram Desktop.

أنشئ ملخصك

افتح TG Wrapped، وأسقط الملف result.json في الصفحة، واختر المحادثات والسنة، ثم اضغط إنشاء. يُحلَّل الملف داخل متصفحك ولا يُرفع.

نصائح

  • اترك الوسائط خارج التصدير: الصور والفيديوهات تجعل الملف ضخماً ولا تُستخدم.
  • قد يستغرق تحليل التصديرات الضخمة جداً بعض الوقت، فأبقِ التبويب مفتوحاً.
  • إذا قال الموقع إن الملف ليس تصدير تيليجرام، فتأكد أنك اخترت JSON وليس HTML، وأنك اخترت الملف result.json.
