टेलीग्राम चैट को JSON में एक्सपोर्ट कैसे करें

टेलीग्राम सारांश बनाने के लिए आपको सिर्फ़ एक फ़ाइल चाहिए: result.json, जो टेलीग्राम डेस्कटॉप से एक्सपोर्ट होती है। मोबाइल ऐप से चैट एक्सपोर्ट नहीं हो सकती, इसलिए आपको Windows, macOS या Linux वाला कंप्यूटर ऐप चाहिए। इसमें करीब दो मिनट लगते हैं।

अपना डेटा एक्सपोर्ट करें

  1. टेलीग्राम डेस्कटॉप खोलें और Settings → Advanced → Export Telegram data पर जाएँ (हिंदी में: सेटिंग्स → एडवांस्ड → टेलीग्राम डेटा एक्सपोर्ट)।
  2. चुनें कि क्या शामिल करना है। सारांश के लिए पर्सनल चैट (और जो ग्रुप आप चाहें) काफ़ी हैं। फ़ोटो, वीडियो, वॉइस मैसेज, स्टिकर और फ़ाइलों का निशान हटा दें, ताकि एक्सपोर्ट छोटा और तेज़ रहे।
  3. फ़ॉर्मेट Machine-readable JSON चुनें (यानी मशीन से पढ़ा जा सकने वाला JSON)। HTML एक्सपोर्ट काम नहीं करेगा।
  4. चाहें तो समय सीमित करें, जैसे सिर्फ़ इस साल का।
  5. Export दबाएँ और इंतज़ार करें। टेलीग्राम आपसे किसी दूसरे लॉग-इन डिवाइस पर इस अनुरोध की पुष्टि करने को कह सकता है।
  6. एक्सपोर्ट वाला फ़ोल्डर खोलें और result.json ढूँढें।

सिर्फ़ एक चैट एक्सपोर्ट करें

चैट खोलें, ऊपर दाएँ कोने में मेनू (⋮) दबाएँ और Export chat history चुनें (यानी चैट का इतिहास एक्सपोर्ट करें)। वही विकल्प रखें: मीडिया के बिना और Machine-readable JSON। टेलीग्राम डेस्कटॉप के वर्ज़न के हिसाब से मेनू के नाम थोड़े अलग हो सकते हैं।

अपना सारांश बनाएँ

TG Wrapped खोलें, result.json फ़ाइल को पेज पर छोड़ें, चैट और साल चुनें और बनाएँ दबाएँ। फ़ाइल आपके ब्राउज़र में ही जाँची जाती है, कहीं भेजी नहीं जाती।

कुछ सुझाव

  • मीडिया को छोड़ दें: फ़ोटो और वीडियो से फ़ाइल बहुत भारी हो जाती है और उनका यहाँ कोई इस्तेमाल नहीं होता।
  • बहुत बड़े एक्सपोर्ट को जाँचने में थोड़ा समय लग सकता है; टैब खुला रखें।
  • अगर साइट कहे कि फ़ाइल टेलीग्राम एक्सपोर्ट नहीं है, तो जाँच लें कि आपने HTML नहीं बल्कि JSON चुना है और result.json ही चुनी है।
