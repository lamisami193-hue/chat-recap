Comment exporter une discussion Telegram en JSON

Pour créer un récapitulatif Telegram, il vous faut un seul fichier : result.json, exporté depuis Telegram Desktop. Les applications mobiles ne peuvent pas exporter les discussions ; il faut donc l’application de bureau pour Windows, macOS ou Linux. Comptez environ deux minutes.

Exporter vos données

  1. Ouvrez Telegram Desktop et allez dans Paramètres → Avancé → Exporter les données Telegram (Settings → Advanced → Export Telegram data).
  2. Choisissez ce qu’il faut inclure. Pour un récapitulatif, les discussions privées (et les groupes de votre choix) suffisent. Décochez photos, vidéos, messages vocaux, stickers et fichiers : l’export reste petit et rapide.
  3. Choisissez le format JSON lisible par machine (Machine-readable JSON). Un export HTML ne fonctionnera pas.
  4. Vous pouvez limiter la période, par exemple à cette année.
  5. Cliquez sur Exporter et patientez. Telegram peut vous demander de confirmer la demande depuis un autre appareil connecté.
  6. Ouvrez le dossier d’export et repérez result.json.

Exporter une seule discussion

Ouvrez la discussion, cliquez sur le menu (⋮) en haut à droite et choisissez Exporter l’historique du chat (Export chat history). Gardez les mêmes options : sans médias et JSON lisible par machine. Les noms des menus peuvent varier légèrement selon la version de Telegram Desktop.

Créer votre récapitulatif

Ouvrez TG Wrapped, déposez result.json sur la page, choisissez les discussions et l’année, puis lancez la génération. Le fichier est analysé dans votre navigateur et n’est pas envoyé.

Conseils

  • Laissez les médias de côté : photos et vidéos alourdissent énormément le fichier et ne sont pas utilisées.
  • Les très gros exports peuvent demander un peu de temps d’analyse ; gardez l’onglet ouvert.
  • Si le site indique que le fichier n’est pas un export Telegram, vérifiez que vous avez choisi JSON et non HTML, et que vous avez sélectionné result.json.
